# OBS-Script
Многофункциональный Lua-скрипт для OBS. Имеет несколько основных фишек: переключатель источников, переключение видимости интерфейса OBS по горячей клавише, сжатие видеофайлов через внешний FFmpeg.

# Подробное описание функций скрипта
## Переключатель источников
Позволяет автоматизировать процесс переключения источников.\n
Основная идея этой функции заключалась в минимизации потребления ресурсов ПК источником захвата дисплея путем его скрытия в моменты когда он не нужен.\n
Для начала работы этой функции нужно включить чекбокс "Включить переключатель источников" во вкладке "Управление переключателем источников" и заполнить некоторые поля ввода во вкладке "Настройки переключателя источников".
В зависимости от заполненных полей ввода могут меняться режимы работы переключателя. Из основных режимов можно выделить несколько:
- Дисплей + Игра\n
При захвате игры источником захвата игры захват дисплея скрывается, чтобы не потреблять лишние ресурсы ПК. При смене фокуса захват игры сбрасывается и захвату дисплея возвращается видимость. Идеально подходит для локальной записи геймплея с минимальными потерями производительности.
- Дисплей + Игра + Окно (Окна)\n
Почти тоже самое, что и режим Дисплей + Игра, только с возможностью использовать источники захвата окон для моментов, когда захват игры по каким то причинам не может захватить игру. В обычном состоянии скрипт скрывает источники захвата окон, а когда окно нужного исполняемого файла получает фокус скрипт автоматически показывает источник захвата окна и скрывает источник захвата дисплея. Захват игры продолжает работать по такой же логике как в режиме без оконных захватов.
- Игра + Окно (Окна)\n
Тоже самое, что и режим Дисплей + Игра + Окно (Окна), только без использования захвата дисплея. Может быть полезен для стримов, когда нужно переключение между окнами и игрой, но показывать полностью весь дисплей не нужно. В моменты когда в фокусе нет подходящих процессов этот режим будет показывать черный экран, если не предусмотреть никаких источников в сцене которые будут покзываться, когда захваты игры и окон не работают.
- Дисплей + Окно (Окна)\n
Почти тоже самое, что и режим Дисплей + Игра, только с использованием одного или нескольких захватов окон, вместо захвата игры. 
- Окно (Окна)\n
Тоже самое, что и режим Игра + Окно (Окна), только без использования источника захвата игры. Также может быть полезен для стримов, когда на трансляцию не должно попадать ничего лишнего.
## Рекомендации по созданию источников
- При добавлении источника захвата окна нужно выбирать строго определенный приоритет подбора окна "Сравнивать заголовок, в противном случае найти окно того же исполняемого файла".
- Лучше всего использовать источник захвата игры с настройкой на захват любого полноэкранного приложения, чтобы не создавать отдельный захват на каждую игру.
## Дополнительные функции переключателя источников
- Растягивать источники по размеру экрана\n
Одноименный чекбокс во вкладке "Управление переключателем источников". Автоматически растягивает источники до размеров холста без сохранения пропорций. Не работает без включенного переключателя источников.
- Включить проверку источника захвата экрана\n
Одноименный чекбокс во вкладке "Управление переключателем источников". Проверяет источник захвата дисплея на активность. Функция может быть полезна для тех, кто часто меняет конфигурацию мониторов. Или для тех случаев когда вы передаете портативную версию программы на другой ПК себе или другому человеку. Проверка происходит при запуске программы и при смене сцены и позволяет избежать моментов, когда вместо дисплея источник захвата дисплея захватывает черный фон. В случае, когда источник не активен у вас автоматически откроется окно свойств источника захвата дисплея и от вас требуется только выбрать нужный дисплей для захвата и подтвердить изменения.
- Черный список процессов источника захвата игры\n
Поле ввода во вкладке "Управление переключателем источников", позволяет задать список процессов при нахождении которых в фокусе будет принудительно скрываться источник захвата игры, чтобы не захватывать нежелательный процесс. Так как источник захвата игры в режиме захвата любого полноэкранного приложения может ошибочно захватить не игру, а какой то плеер. Черный список захвата игры работает независимо от состояния переключателя.
- Черный список сцен переключателя источников\n
Поле ввода во вкладке "Управление переключателем источников", позволяет задать список сцен, в которых переключатель сцен будет временно отключаться. Функция полезна для тех, кто использует OBS и для записи и для стримов одновременно.
## Горячие клавиши 
Переключение интерфейса OBS включено по умолчанию, но не назначено в настройках горячих клавиш самого OBS. Если главное окно программы скрыто на панель задач или в трей, то при нажатии горячей клавиши оно вызовется. Если главное окно открыто, то при нажатии горячей клавиши оно свернется на панель задач или в трей. Можно принудительно выключить сняв чекбокс в настройках скрипта. Дополнительная функция "Открывать окно скриптов вместе с OBS" просто будет открывать окно настроек скрипта при нажатии горячей клавиши. Удобно для тех кто часто пользуется функцией сжатия видеофайлов.
## Сжатие видеофайлов
Позволяет выбрать видеофайл, выбрать степень сжатия от 0 (лучшее качество) до 51 (худшее качество) и сжать его используя кодирование x264 и аппаратное ускорение для декодирования через внешний FFmpeg. FFmpeg.exe должен находиться в одной папке со скриптом для корректной работы функции сжатия. Совет по выбору степени сжатия: выбирайте 20 если нужно качество практически как у оригинала, но со сниженным весом файла, выбирайте 26 если нужен баланс между приемлемым качеством и еще сильнее уменьшенным весом файла. Сжатие требует много мощностей ЦП, мощнее ЦП = быстрее сжатие. По завершени. процесса сжатия у вас откроется окно проводника с выделенным сжатым файлом с припиской "Compressed".
## Локализация
Сейчас доступна русская и английская версия локализации. папка locale должна находиться рядом со скриптом иначе у вас вместо понятной локализации будут ключи для локализации.
